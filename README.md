# EMD (Everything Mobile Development)

Build, run, check and prove mobile changes from any coding agent, without opening Xcode or Android Studio.

```sh
npx emd-agents setup
```

Status: pre-release. See [docs/vision.md](docs/vision.md) for what EMD is and [AGENTS.md](AGENTS.md) for how to work on it.
