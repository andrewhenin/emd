# Contributing

Commands, folder map and rules are in [AGENTS.md](AGENTS.md). Read it before changing anything.

- Open pull requests as drafts.
- Title them as a Conventional Commit (`feat:`, `fix:`, `docs:`, `chore:`). Squash merges use the PR title, and CI checks it.
- Link an issue for `feat` and `fix` PRs.
- Run lint, typecheck and tests locally first (see Definition of done in AGENTS.md).
- `npm run test:e2e` needs macOS and Xcode and doesn't run in CI.
